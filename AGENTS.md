- This is a GitHub profile repository; the user-facing content is `README.md`.
- Keep the profile concise, technical, and written in Brazilian Portuguese; do not turn it into a LinkedIn-style full resume unless explicitly requested.
- Preserve the header contact icons, construction notice, technology icons, and `Repositórios` section when editing unrelated content.

- No automated verification command is configured; review the Markdown diff and rendered content manually.
